# Infinite Leverage v1 — retired

This v1 plugin (the 8-agent team) is retired. Its routing table, agents and setup
commands (`/infiniteleverage-init`, `-onboard`, `-patch`) no longer apply.

Infinite Leverage v2 ships from https://github.com/edge8-ai/infinite-leverage: four
agents — product-manager, developer, qa, devops — installed per project with `/il-adopt`
or `/il-project`. See the root README of this repo for how to move to v2.
